Frequently asked questions

How the educational demo works, what is simulated, and which values are safe to use.

DEMO HELP
NOT OFFICIAL GUIDANCE
Is this the official CPGRAMS website?

No. This is an unofficial, student-built educational replica. It is not connected to the Government of India, DARPG, NIC or any ministry. No real grievance is filed and no government officer receives anything you submit.

Can I file a real complaint here?

No. The forms accept fictional demonstration data only. For a real complaint, use the official CPGRAMS portal at pgportal.gov.in.

What credentials does the demo request?

None. The demo never asks for a government username, password, Aadhaar, PAN, OTP, CAPTCHA value or other real credential. The sign-in page only offers a shared "Demo Citizen" session. If any page asks for those values, do not enter them.

How do I get a demo registration number?

Continue as a Demo User, open Lodge Public Grievance, complete the required fields and submit. The acknowledgement page displays a reference such as CPGRAMS-DEMO-{{ current_year }}-00004 and a verification code. Both are required by the status page.

How do I track a grievance?

Open View Status and enter both the registration number and verification code. The page shows the stored details and the full simulated event timeline.

What are the seeded demo records?

The database starts with three fictional records. They are safe to explore:

  • CPGRAMS-DEMO-{{ current_year }}-00001 · DEMO-CITIZEN-001 · Closed
  • CPGRAMS-DEMO-{{ current_year }}-00002 · DEMO-CITIZEN-002 · Under process
  • CPGRAMS-DEMO-{{ current_year }}-00003 · DEMO-CITIZEN-003 · Received

Seeding runs only when the complaint table is empty, so normal startup does not overwrite user-created records.

How do reminders and feedback work?

A reminder or clarification appends a Reminder event to the local timeline. Feedback appends a Feedback event and stores the rating. Neither action reaches a government officer, creates an appeal or changes a real case.

Where is my data stored?

In a local SQLite file, by default cpgrams-demo/data/cpgrams_demo.db. Attachments are stored under a random name in cpgrams-demo/data/uploads. Nothing is uploaded to a third party unless the optional dashboard adapter is explicitly configured by the operator.

Read the demo data policy.

How do I reset the demo?

Stop the server and run cd cpgrams-demo && python -m app.seed --reset. This deletes all demo complaints, events, feedback, users and messages, then recreates the three seeded records. It is destructive by design.

Are all languages translated?

English, Hindi and Tamil have full core translations for navigation and essential messages. The selector lists the reference portal's language set, but unsupported languages clearly fall back to English rather than pretending to be fully translated.

Does the dashboard integration work?

An optional adapter is included for the existing local complaint-intelligence dashboard's authenticated POST /ingest/json contract. It is disabled unless DASHBOARD_INGEST_URL and a token are configured. Failures never delete the local record. See the README for setup and limitations.

Why does the interface look like the official site?

The layout is intentionally reference-inspired for interface research. The title, emblem, disclaimers, colours and copy are original or neutral, and every page states that this is an unofficial demo. No government logo or official identity credential is reproduced.
