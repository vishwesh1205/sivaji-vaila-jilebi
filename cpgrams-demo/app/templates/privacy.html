Privacy & Demo Data Policy

What this local educational demo stores, what it deliberately does not collect, and how to remove everything.

LOCAL ONLY
NO ANALYTICS

1. Unofficial status

This application is an unofficial educational replica. It is not connected to the Government of India, CPGRAMS, DARPG, NIC or any ministry. Nothing submitted here is a real government grievance.

2. What is stored

  • Demo complaint details you enter: complainant reference, subject, category, organisation, region and description.
  • Optional attachment metadata and the file itself, stored under a random local filename.
  • Demo events, feedback, contact messages and fictional profile details.
  • A signed local session cookie containing the demo display name and demo account reference.
  • A language preference cookie.

3. What is never requested

  • Government usernames or passwords.
  • Aadhaar, PAN or other national identifiers.
  • OTPs, CAPTCHA responses or security answers.
  • Real phone numbers, financial information or sensitive personal data.

Do not enter real personal or sensitive information. The demo is not designed or secured for it.

4. Where data lives

By default, records are stored in cpgrams-demo/data/cpgrams_demo.db and attachments in cpgrams-demo/data/uploads on the computer running the application. The SQLite file is not encrypted. It is not sent to any external service.

5. Optional dashboard adapter

If, and only if, an operator explicitly sets DASHBOARD_INGEST_URL and a bearer token, newly submitted demo complaints are also sent to that configured local endpoint. The local record is always retained, even if the network request fails. No adapter is configured by default and no request is ever sent to the real CPGRAMS portal.

6. Cookies

The demo uses three first-party cookies: a signed demo session, a short-lived flash message and a language preference. No advertising, analytics or third-party tracking cookies are used.

7. Logs

The local web server may print request logs to the terminal. The application itself does not create an analytics trail. Error messages may contain form values in local server logs if an unexpected failure occurs.

8. Retention and deletion

Data remains until you delete it. To remove all demo records and recreate the seed data, stop the server and run:

cd cpgrams-demo
python -m app.seed --reset

To delete the database and uploads manually, remove data/cpgrams_demo.db and the files under data/uploads. The database is recreated on the next startup.

9. Real complaints

For a real grievance, use the official CPGRAMS portal at pgportal.gov.in. This project cannot forward, store, escalate or resolve a real complaint.

EDUCATIONAL DEMO — UNOFFICIAL REPLICA.

NOT CONNECTED TO THE GOVERNMENT OF INDIA. NO REAL GOVERNMENT GRIEVANCE IS FILED.
